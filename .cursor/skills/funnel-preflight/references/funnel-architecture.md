# End-to-End Funnel Architecture Checklist

Use Gate F to confirm each box. Strike what this offer intentionally omits — omission must be conscious.

## 1. Strategy spine (before pages)

- [ ] One primary product locked
- [ ] Price + guarantee locked
- [ ] Avatar + promise + mechanism locked
- [ ] Brand kit locked (Wedge vs Bignition vs other)
- [ ] Primary traffic source + capture URL locked
- [ ] Success metric (CPL, CPA, or ROAS) named

## 2. Traffic layer

- [ ] Paid click campaigns (platform, offer angle, destination URL)
- [ ] LinkedIn organic plan (posts → notes CTA → quiz/opt-in URL)
- [ ] YouTube organic plan (scripts → description/notes CTA → same URL)
- [ ] Retargeting audiences defined (video viewers, quiz starters, opt-ins, visitors)

## 3. Capture layer

### Quiz funnel path

- [ ] Result buckets named (3–5)
- [ ] Questions map to buckets / qualification
- [ ] Email gate placement chosen
- [ ] Result page copy + recommended next step per bucket
- [ ] Tags/fields into CRM
- [ ] Segmented follow-up outline per bucket (3–5 emails)

### Static lead magnet path (optional parallel or instead)

- [ ] Magnet title + format + delivery mechanism
- [ ] Opt-in page (one promise, one CTA)
- [ ] Instant delivery email
- [ ] Nurture → bridge to VSL/sales

## 4. Persuasion layer (Benson)

- [ ] Bridge page or thank-you that sets up the VSL (if used)
- [ ] VSL page (headline + player + delayed buy button pattern as needed)
- [ ] Written sales letter under/near video (optional but common)
- [ ] Proof stack (testimonials, results, credibility)
- [ ] Offer stack (bonuses, price, guarantee, urgency)
- [ ] Checkout page (minimal fields)

## 5. Revenue maximization layer

- [ ] Order bump (optional)
- [ ] Upsell 1 page + yes/no links
- [ ] Upsell 2 (optional)
- [ ] Downsell only on upsell decline (optional)
- [ ] Thank-you / onboarding instructions

## 6. Email & CRM layer

- [ ] Delivery / access email
- [ ] Abandon / incomplete quiz or checkout recovery
- [ ] Core nurture (Benson-aligned problem → mechanism → offer)
- [ ] Post-purchase onboarding
- [ ] Referral or "share" ask (Polish after-unit)

## 7. Measurement layer

- [ ] UTMs on every traffic source
- [ ] Pixel(s) + lead event + purchase event
- [ ] Dashboard: spend, leads, sales, AOV, refunds
- [ ] First optimization hypothesis (what you will fix first if CPL is high vs CVR is low)

## 8. Fulfillment layer

- [ ] Access provisioning automation or checklist
- [ ] Support inbox / person named
- [ ] Refund process documented
- [ ] Live session calendar / community invite if applicable

## Minimal viable funnel (if they insist on speed)

Only after Gates A–B lock:

1. Opt-in **or** quiz  
2. Thank-you with VSL link  
3. VSL + checkout  
4. Thank-you + delivery email  

Add bump/OTO and segmented email once the front end converts.
