# Funnel Preflight Skill

Project skill that stops cart-before-horse funnel builds.

## Location

`.cursor/skills/funnel-preflight/`

## Trigger examples

- "Run Funnel Preflight"
- "I want a funnel for this book/program"
- "Before we build ClickFunnels…"
- "Quiz funnel + LinkedIn/YouTube promo — start with questions"

## Behavior

Phased interview (Gates A–F). Refuses VSL/pages/ads until Product & Offer and Economics are locked. Writes briefs to `Funnel Preflight/`.
