# Funnel Preflight

Stop building until the offer is clear. This skill runs a phased interview, refuses
page/ad/VSL work until gates pass, and writes a **Funnel Preflight Brief** the rest
of the launch can follow.

## Hard rule (never violate)

Do **not** draft VSLs, sales pages, opt-in pages, ad copy, email sequences, quiz
questions, LinkedIn posts, or YouTube scripts until **Gate A (Product & Offer)** and
**Gate B (Economics & Backend)** are marked `LOCKED` in the brief.

If the user asks to "just start the pages" or "write the VSL first," refuse briefly,
point at the open gate questions, and resume the interview.

Benson / BNSN is used **after** preflight — for VSL, sales letter, and much of the
email — not as a substitute for knowing what is being sold.

## When to use

- New book, digital book, live program, online program, cohort, membership, or hybrid
- "I want a funnel / ClickFunnels / quiz funnel / VSL"
- Promo planning for LinkedIn + YouTube that drives to opt-in or quiz
- Any moment the conversation jumps to creative before product clarity

## How to run the interview

1. Tell the user you are running **Funnel Preflight** and that build work is blocked until gates lock.
2. Work **one gate at a time**. Ask 3–6 questions per turn. Do not dump the whole bank.
3. After each answer, mirror back a one-line decision and mark status: `OPEN` | `DRAFT` | `LOCKED`.
4. Read `references/question-bank.md` when you need the full question list for a gate.
5. Read `references/marketer-frameworks.md` when explaining *why* a question matters.
6. Read `references/funnel-architecture.md` when mapping the end-to-end path.
7. Persist progress into a brief using `assets/preflight-brief-template.md`.
8. Save the brief under `Funnel Preflight/` in this vault as:
   `Funnel Preflight/YYYY-MM-DD - <Offer Short Name> - Preflight Brief.md`
9. Only when Gates A–E are `LOCKED` (Gate F may be `DRAFT` if creative is deferred) produce the **Go / No-Go** section and the recommended build order.

### Interview style

- Be direct. Prefer forced choices over open essays when possible.
- Challenge vagueness: "a program" is not locked — format, delivery, price, and promise must be concrete.
- If they flip-flop on product type, reopen Gate A and wipe dependent decisions (price, upsells, VSL angle).
- Capture exact dollar amounts, not ranges, before locking Gate B.
- For brand: force **Wedge colors** vs **Bignition colors** (or explicit third brand kit). No "we'll decide later."
- **Name correction:** The brand is **Bignition** (not "Big Mission"). If speech-to-text or the user sounds like "Big Mission," always write and confirm **Bignition**.

## Gates (in order)

| Gate | Name | Must lock before… |
|------|------|-------------------|
| **A** | Product & Offer | Anything else |
| **B** | Economics & Backend | Pages, checkout, VSL offer section |
| **C** | Avatar & Promise | Ads, quiz, lead magnet, VSL |
| **D** | Brand & Creative System | Any designed page or video |
| **E** | Traffic & Capture Plan | Ad spend, LinkedIn/YouTube CTAs |
| **F** | Funnel Map & Assets | Build sprint (may leave creative drafts open) |

### Gate A — Product & Offer

Force a single primary SKU:

- What are we selling? Book / digital book / online program / live program / hybrid / other
- Exact working title
- Delivery: PDF, print, self-paced course, cohort, live workshop, membership, 1:1, etc.
- Core transformation in one sentence (outcome, not features)
- Who it is **not** for
- One primary CTA after purchase (consume / show up / implement)

Do not proceed if two primary products are competing. Stack secondary products as upsells later.

### Gate B — Economics & Backend

- Front-end price (and payment plan if any)
- Order bump? Yes/No + what + price
- Upsell 1 / Upsell 2? Yes/No + what + price
- Downsell path? Only after an upsell "no" — what + price
- Refund / guarantee terms
- Fulfillment owner and timeline (who ships access, when)
- Target CPA / allowable ad cost (even a rough number)

### Gate C — Avatar & Promise

- Single primary avatar (job/role, situation, desire, fear)
- Big problem in their words
- Mechanism / unique approach name (feeds Benson Solution step)
- Proof assets available now (stories, results, logos, testimonials) vs. still needed
- Awareness level for cold traffic (unaware → most aware)

### Gate D — Brand & Creative System

- Brand kit: **Wedge** vs **Bignition** vs named other
- Primary / secondary / accent colors confirmed into the brief
- Logo file location or "create later" (flag risk)
- Voice: Randy as narrator? Host? Expert interviewer?
- Visual style notes for pages and VSL slides

### Gate E — Traffic & Capture Plan

- Primary paid channel for click campaigns (Meta, Google, LinkedIn Ads, YouTube Ads, other)
- Organic amplifiers: LinkedIn posts/carousels, YouTube scripts (notes CTAs → quiz/opt-in)
- Lead capture vehicle: quiz funnel and/or static lead magnet and/or webinar/VSL direct
- If quiz: result buckets planned **before** questions (bucket-back method)
- If other lead magnet: exact deliverable title + format
- Email tool / CRM / ClickFunnels (or equivalent) of record
- Tracking: UTM convention, pixel(s), thank-you / purchase events

### Gate F — Funnel Map & Assets

Map the path end-to-end (see `references/funnel-architecture.md`), then list every asset:

Typical click → quiz/opt-in → result/thank-you → bridge → Benson VSL/sales page → checkout → bump → upsell → downsell → thank-you → email nurture.

For each asset: owner, status (`needed` / `draft` / `ready`), dependency.

Hand off copy work to Benson structure only after this map exists:

1. Snap Suggestion (Lead)
2. Story
3. Problem
4. Solution / Mechanism
5. Offer / Close (proof, price, bonuses, guarantee, urgency, future pace, CTA)

## Output: Funnel Preflight Brief

Always produce or update the brief file. Fill every section; use `TBD` only inside `OPEN` gates, never silently.

At the top of the brief keep:

```markdown
## Gate status
- A Product & Offer: LOCKED|DRAFT|OPEN
- B Economics & Backend: …
- C Avatar & Promise: …
- D Brand & Creative System: …
- E Traffic & Capture Plan: …
- F Funnel Map & Assets: …
## Build permission
DENIED until A+B LOCKED. ALLOWED for asset drafting when A–E LOCKED.
```

End with:

- **Go / No-Go** — one paragraph
- **Build order** — numbered next actions (pages last if offer still soft)
- **Open risks** — fulfillment, proof gaps, brand assets missing

## After gates lock

When the user is ready to build:

1. Confirm brief path and gate statuses.
2. Draft assets in this order unless they override: quiz/lead magnet → opt-in → thank-you/bridge → VSL (Benson) → sales/checkout → OTOs → email → LinkedIn/YouTube promo with notes CTAs to the quiz/opt-in.
3. Keep the brief as source of truth; if product or price changes, reopen Gate A/B and pause creative.

## Do not

- Invent a product, price, or upsell "for now"
- Start Benson VSL copy with an unlocked offer
- Skip brand color choice
- Design quiz questions before result buckets
- Treat LinkedIn/YouTube as the funnel — they are traffic; capture still needs a URL
