## Models (Randy — do not copy; use to spark yours)

- **GRIT / hiring:** Don’t ask if they’re capable — make them *do* things so evidence shows it.  
- **Wedge:** Somebody has to lose for you to win — build the call so the prospect sees the income that’s not doing the job.  
- **Sales meeting:** Spreadsheet liars club → put a producer on the hot seat: Define → Defend → Develop.
